Посмотреть историю коммитов

```bash
git log
```


```bash
git reset --hard HEAD~1
```
- Удаляет последний коммит
- Сбрасывает индекс (staging)
- Стирает изменения из рабочей директории


git rev-list --count HEAD

```bash
git reset --soft HEAD~5
```

- Удаляет последний коммит
- Но оставляет все изменения в staging area.
То есть коммит пропал, но файлы остаются «как будто вы их только что добавили через git add».
